# Capstone Project - Nova FCT Data Analytics
Capstone Project on the course Data Analysis Using the Python Programming Language, developed on **VSCode**. \
Each group or individual student was assigned a case study, in which EDA was performed.

## Libraries
- **Pandas**
- **Matplotlib**
- **Seaborn**
